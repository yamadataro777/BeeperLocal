通常アプリと試用ZIPは0.9.5。LINE・Instagram・Slack・X・MessengerのUI・暗号化保存・権限付きMCPを統合した。Apple公証、チケット、Gatekeeper、Slack公開Client IDと専用URLの保存・配布有効化は確認済み。これらを未実施として繰り返さない。

## 作業の順序

1. [今回の見直し](DEVELOPMENT_REVIEW_20261003.md)の受入条件に従って、旧版移行・不要分岐を整理し、関連テストと回帰確認を完了する。通常配置0.9.5と開発ソースを区別する。
2. 本人操作による新Slack認証と、同意した試用環境での5サービスのログイン・受信・保存・再起動検索を確認する。実送信は本人が宛先と本文を承認した範囲だけ。
3. 実AIクライアント1製品でMCP導入、許可した会話の参照・検索、権限取消しを確認し、版付きの導入手順を整える。
4. 日常運用のスリープ復帰・物理回線断・長時間運転・認証失効を確認する。同期範囲と欠落の可能性を実測と分けて説明する。
5. 新候補を配布する場合は、現行手順で署名・公証・梱包・展開後検証を行う。旧データの移行・互換を実装しない。非対応データは勝手に初期化せず、その状態を利用者に示す。
