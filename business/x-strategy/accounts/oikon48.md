## フォローさせる仕掛け

- 版番号つきの抜粋を毎回出す（2.1.228から2.1.287まで確認）。
- 速報のあとに、設定の手順をもう1投稿で足す（AGENTS.md対応の速報187,671表示 → 設定手順56,585表示・ブックマーク210）。
- 自作をコマンドつきで置く（`/plugin marketplace add oikon48/prompt-rail`）。
- 同じ名前を繰り返す（#ClaudeCode深掘りガイド、Weekly Updates）。
- フォロー依頼や固定の締め文はない。

## 1行目の型

- 版番号＋抜粋:「Claude Code 2.1.287 (抜粋)」
- 機能名＋結論:「Claude Codeでついに AGENTS.md をサポート！！」
- 設定の見出し:「【Claude Code で AGENTS.md をサポートする設定】」
- まとめ番号:「OpenAI DevDay 2026まとめ①」
- 自作の告知:「Claude Code plugin "prompt-rail" is out!」
- 感想:「現状 Claude Opus 5.5 の満足度が高すぎて…」

## 読み取れること

- 型は「1つの道具に絞る → 公式の更新をその日のうちに日本語にする → 設定手順を足す → 自分で触った差分を足す」。
- 紹介・翻訳が中心だが、訳すだけでは終わらず、手順か分類を足している。
- 毎日出す「定番」（抜粋）があるので、フォローする理由がはっきりしている。
- 立ち上がりは、話題が急に盛り上がった週に乗れたことが大きい。同じ波がいつ来るかは選べない。
