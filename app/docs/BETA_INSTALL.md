# BeeperLocal ベータ版 — はじめに

Apple Silicon（M1以降）、macOS 13以降が対象です。この案内はApple公証とSlack配布設定の検査を通過したZIPだけに同梱されます。ベータ版のため、別Macでの各サービスの動作確認にご協力ください。

1. ZIPを展開し、BeeperLocal.appをアプリケーションフォルダへコピーします。旧版を終了してから起動してください。
2. 各サービスの接続設定で本人ログインします。PythonやNodeのインストールは不要です。
3. Slackは「Slackにログイン」を押し、ブラウザでワークスペースと権限を確認します。管理者の承認が必要な場合はSlackの案内に従います。認証完了後にBeeperLocalへ戻って再接続してください。
4. LINEはスマートフォンでQRを承認します。本家Beeper・Chrome版LINEと同じアカウントを交互に連携すると、もう一方がログアウトする場合があります。
5. Instagram、X、Messengerは専用ログイン画面で本人認証します。Instagramの確認通知が来ない場合は、公式画面に表示される別の確認方法を選んでください。

macOSのキーチェーン確認は本人が許可してください。起動を拒否された場合は保護設定を無効にせず、表示内容とアプリの版を開発者へ知らせてください。パスワードやトークンを送る必要はありません。

本文はEnterで改行、⌘Enterで送信します。画像はJPEG・PNGを1枚ずつ、4MiB以内で送れます。送信結果が不明な場合は相手側・履歴を確認するまで再送しないでください。アプリ終了中とMacのスリープ中は受信しません。下書きはアプリ終了時に消えます。

更新は開発者から受け取った新しい版へ手動で差し替えます。自動更新の配布先はまだ設定されていません。履歴範囲などの制限はアプリ内「使い方・対応範囲」と同梱資料を確認してください。

公証・Slack設定の検査結果は`distribution-checks.json`、今回の検証範囲は`desktop-VERSION-verification.json`に記録されています。公証は各サービスの実送受信の成功を保証するものではありません。
