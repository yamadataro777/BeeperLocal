# BeeperLocal 0.9.3 — はじめに（内部検証候補）

今回の画像送信・相手アイコン・認証説明の改善は同梱の `USER_FEEDBACK_0_9_3.md` を参照してください。画像送信は実装と自動試験を完了した段階で、実アカウントでの着信は未検証です。

5サービスすべてでMCPを使えます。対象サービスの「接続設定」→「MCP接続」で、許可する会話と閲覧／送信を選んで登録します。同梱の `MCP_0_9_1.md` を参照してください。

このZIPは一般公開前の内部検証候補です。Apple公証がなく、新しいMacではGatekeeperに拒否されます。macOSの保護設定を無効化して起動しないでください。公証済み版を配布するまで、初めて使う方への一般配布は保留します。

Apple Silicon（M1以降）専用です。macOS 13以降をビルド対象とし、同梱実行ファイルと圧縮されたPython内ライブラリの要求OSを検査します。実行確認はmacOS 26.5.2のこのMacのみで、macOS 13実機・別Mac・別OSユーザーの初回ログインは未検証です。空の保存領域・未ログインの画面検証を、別Macの成功と同一視しません。詳細は同梱の `FRESH_MAC_AUDIT.md` を参照してください。

## 起動と連携

1. ZIPを展開し、`BeeperLocal.app`をコピーします。以前のアプリを終了してから起動してください。既存版と同時に接続しないでください。
2. 左のサービスを選び、接続設定を開きます。Python・Nodeの追加インストールは不要です。
3. LINEはスマートフォンでQRを承認します。本家Beeper・Chrome版LINEとの同一アカウントの同時利用はできません。連携を切り替えると、もう一方がログアウトする場合があります。Instagramは「Instagramにログイン」で開く公式サイトの専用画面で本人確認を進め、右上の「ログイン完了・接続する」を押します。通知が届かない場合は、公式画面に表示される別の確認方法を選んでください。Terminalに保存成功が表示されたらアプリで再接続します。XとMessengerも専用のログイン画面で本人認証します。
4. Slackの新規ログインは、この候補では利用できません。画面にも理由を表示し、ボタンを無効にしています。既存のキーチェーン連携は継続できます。新規ログインは配布元の設定を含む更新版が必要です。

macOSのキーチェーン確認は本人が画面で許可してください。開けない場合は表示文言を開発者へ知らせてください。認証情報をチャットへ貼る必要はありません。

## 日常の操作

- 起動中は接続したサービスの会話を順番に同期します。サービスを切り替えても他サービスの同期は続きます。会話数が多いほど巡回に時間がかかります。
- 未読はこのMacで集計します。通知ボタンで通知を許可できます。通知には本文や相手名を表示しません。
- Instagram・Slack・Xの過去履歴ボタンで、サービスから取得できる範囲を追加します。取得は再起動後も再開できます。保存済み履歴は100件ずつ過去へ表示できます。
- Enterで改行、⌘Enterで送信。Messengerの1対1テキスト送信も使えます。下書きはサービス・会話ごとに保持しますが、アプリ終了時に消えます。
- 送信結果が不明な場合は、履歴や相手側で確認してから再送してください。自動再送はしません。
- LINEのログインが無効になったときは「再ログインが必要です」と表示し、送受信・履歴同期を止めます。保存履歴と入力中の下書きは残ります。本家Beeper・Chrome版との再接続を交互に繰り返さず、使うアプリを決めてから「QRコードで再連携」を押してください。
- 画像は5サービスで1枚ずつ送信できます。JPEG・PNG、4MiB・2,500万画素まで。画像を選択・貼り付け・ドロップし、プレビューで確認して「この画像を送信」を押します。文章は下書きに残ります。Slackはファイル権限の追加承認が必要な場合があります。
- X・Instagramの画像・動画・音声は表示ボタンで読み込みます。4MiB以下の対応形式のみです。動画・その他のファイル送信、新規グループ作成は未対応です。
- LINE・Instagramの相手アイコンとSlackプロフィールは暗号化して保存し、次回起動時も利用します。キーチェーン確認のキャンセル後は、本人が再接続するまで繰り返しアクセスしません。OSの継続許可は本人がmacOSの「常に許可」で設定できます。
- ⌘Kで現在のサービスの保存済み最新10,000件を検索し、最大50結果を表示します。
- 各サービスの保存管理から受信停止・保存再開・ローカル削除ができます。削除は対象件数を確認してから実行します。サービス上の原本やログインは削除しません。

## 取得できない範囲

LINEの過去履歴は直近100件の範囲です。Messengerはこの端末へ配信された履歴を保存し、暗号化バックアップを復元しません。サービス側の保存期間や取得権限を超えて過去履歴を取得することはできません。

削除同期はInstagramの接続中イベント、Xの署名済み削除、Messengerの送信者取消、Slack APIが返す削除情報に限ります。LINEや、停止中を含む全サービスの完全な削除・編集同期は未対応です。既読も元サービスとは同期しません。

Slackは約65秒に1ページずつ会話・スレッドを巡回します。LINE・Instagram・Messengerは対応する受信ストリームも使います。アプリ終了中・Macのスリープ中は受信しません。

## 更新と問い合わせ

署名付き更新の確認・適用機能を追加しましたが、今回の候補では配布先が未設定です。「更新を確認」は設定不足を案内します。公開設定が済むまでは、アプリ終了後に新しい版をコピーしてください。設定後の更新は本人が適用を選ぶと再起動し、下書きがある間は適用できません。

「使い方・対応範囲」の診断情報と、問題が起きた操作を開発者へ伝えてください。本文・相手名・ID・トークンは診断情報へ含めません。

詳しい実装範囲と公開設定は同梱の`INBOX_0_9.md`と`USER_FEEDBACK_0_9_3.md`、検証結果は`desktop-0.9.3-verification.json`を参照してください。
